# הסטודיו של תמימה

מערכת לסטודיו לקרמיקה: אתר ללקוחות, ניהול לתמימה, ואזור אישי לסטודנטים. בנויה לטלפון, לטאבלט ולמחשב.

## שלושת הקישורים

| קישור | למי | כתובת |
|---|---|---|
| האתר | לקוחות: סדנאות, קורס, הזמנה ותשלום, "ההזמנה שלי" | https://az0260663-byte.github.io/TEMIMA/ |
| הניהול | תמימה: יומן, חוגים, סדנאות, לקוחות, קבלות, זיכויים והגדרות | https://az0260663-byte.github.io/TEMIMA/studio.html |
| האזור האישי | סטודנט, רק דרך הקישור האישי שמגיע במייל | נשלח לכל סטודנט |

כלי פנימי (לא לשליחה לתמימה): `demo-app.html`. כל המבטים בדף אחד, עם חלונית "מאחורי הקלעים", תפריט כלים (קידום זמן, הדגמת הודעה כפולה מסאמיט, איפוס) ומסך בדיקות הנגישות והאבטחה.

## פיתוח: הפעלה במחשב

1. מעתיקים את `server/.env.example` לקובץ `server/.env` וממלאים את הסוד של גוגל (לא לשלוח בצ'אט).
2. מפעילים:

```bash
node server/server.js
```

3. נכנסים ל-`http://localhost:8123/studio.html`. מסך כניסה, ואחרי כניסה עם חשבון הסטודיו הנתונים נטענים מהשרת ונשמרים אחרי כל פעולה.

בלי שרת (למשל בגיטהאב) הניהול עובד כדמו כמו קודם. האתר ללקוחות והאזור האישי עדיין דמו (שלב 5).

בדיקות:

```bash
node tests/store.test.js
```
