# הסטודיו של תמימה

מערכת לסטודיו לקרמיקה: אתר ללקוחות, ניהול לתמימה, ואזור אישי לסטודנטים. בנויה לטלפון, לטאבלט ולמחשב.

## שלושת הקישורים

| קישור | למי | כתובת |
|---|---|---|
| האתר | לקוחות: סדנאות, קורס, הזמנה ותשלום, "ההזמנה שלי" | https://az0260663-byte.github.io/TEMIMA/ |
| הניהול | תמימה: יומן, חוגים, סדנאות, לקוחות, קבלות, זיכויים והגדרות | https://az0260663-byte.github.io/TEMIMA/studio.html |
| האזור האישי | סטודנט, רק דרך הקישור האישי שמגיע במייל | נשלח לכל סטודנט |

כלי פנימי (לא לשליחה לתמימה): `demo-app.html`. כל המבטים בדף אחד, עם חלונית "מאחורי הקלעים", תפריט כלים (קידום זמן, הדגמת כשל בזיכוי, איפוס) ומסך בדיקות הנגישות והאבטחה.

## הקבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | דף האתר ללקוחות |
| `studio.html` | דף הניהול של תמימה |
| `student.html` | דף האזור האישי של סטודנט |
| `demo-app.html` | הכלי הפנימי: כל המבטים יחד |

| `studio.js` | הניהול של תמימה |
| `student.js` | האזור האישי: שיעורים, השלמות, תשלומים, מדיניות וסיום הקורס |
