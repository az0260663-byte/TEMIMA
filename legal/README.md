# מסמכי עמידה בחוק: האתר ללקוחות

בדיקת mom מ-26.10.2026. חל רק על האתר ללקוחות (`index.html`, `site.js`).

| קובץ | מה יש בו |
|---|---|
| `accessibility-statement.md` | נוסח הצהרת הנגישות (העמוד באתר: `#/client/accessibility`) |
| `privacy-policy.md` | נוסח מדיניות הפרטיות (`#/client/privacy`) |
| `terms-and-cancellation.md` | נוסח התקנון ומדיניות הביטול (`#/client/terms`) |
| `consent-texts.md` | הנוסחים הקצרים בטפסים |
| `accessibility-checklist.md` | טופס הבדיקה של הנציבות, לכל תבנית עמוד |
| `open-items.md` | מה עוד חסר, ממי |

העמודים באתר נבנים מאותו תוכן. פרטי העסק (שם משפטי, מספר עוסק, מייל) מוגדרים פעם אחת ב-`data.js` (`bizLegalName`, `bizId`, `bizEmail`), ומופיעים באתר רק אחרי שמולאו.

מומלץ שעורך דין יעבור פעם אחת על התקנון ועל מדיניות הפרטיות.
